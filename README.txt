LOORCHIK'S PEARL CANNON — FLIGHT PLANNER

Open index.html in a modern browser. The site works as a static page; an internet connection is only needed for the optional Google Fonts import. The looping video background is the supplied Minecraft orbit recording. If the video cannot play, the site falls back to a locally rendered model extracted from the Litematica schematic.

CONTROLS
- The cannon video loops automatically behind the page.
- Use the calculator tabs to convert dispenser items or a target distance.

CALCULATOR
- Confirmed distance: items per dispenser × 125 blocks.
- Input chest total: twice the items per dispenser.
- Recorded test times appear as measured results.
- Between 1,000 and 10,000 blocks, missing times are interpolated from nearby tests.
- Above 10,000 blocks, the approximate 4,000–10,000 block time pattern is extrapolated and labeled as an estimate.
- Below 1,000 blocks, no time estimate is shown because there is no measurement to support it.
